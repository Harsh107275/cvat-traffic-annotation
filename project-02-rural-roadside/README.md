# Project 2: Rural Roadside Market Annotation

## Project Overview
This is a personal practice project created using CVAT (Computer Vision Annotation Tool) to develop practical image data annotation skills.

## Image Description
The image shows a rural roadside scene containing a tractor, cars, motorcycles, people, and cows.

## Tools Used
- CVAT (Computer Vision Annotation Tool)
- Bounding-box annotation
- GitHub

## Annotation Tasks
- Object identification and labeling
- Bounding-box annotation
- Vehicle and animal annotation
- Identifying objects in a real-world scene

## Skills Demonstrated
- Image data annotation
- Object labeling
- Bounding-box creation
- Identifying objects for computer vision tasks

## Project Status
Bounding-box annotations were created in CVAT. The exported annotation dataset is not included because export is currently unavailable without an upgrade.

## Project Purpose
This project demonstrates hands-on practice with image annotation for computer vision datasets.

**Project Type:** Personal Learning and Practice Project
